# Chapter 14: I/O

## 1. Referencing Files and Directories

### File Class (Legacy)

```java
import java.io.File;

// Créer File object (ne crée PAS le fichier physique)
File file = new File("data.txt");
File file2 = new File("/home/user/data.txt");
File file3 = new File("C:\\Users\\data.txt");  // Windows

// Avec répertoire parent
File parent = new File("/home/user");
File child = new File(parent, "data.txt");  // /home/user/data.txt

// Vérifier existence
boolean exists = file.exists();

// Fichier ou répertoire?
boolean isFile = file.isFile();
boolean isDirectory = file.isDirectory();

// Propriétés
String name = file.getName();           // "data.txt"
String path = file.getPath();           // "data.txt" ou chemin complet
String absolutePath = file.getAbsolutePath();  // Chemin absolu
long size = file.length();              // Taille en bytes
long modified = file.lastModified();    // Timestamp

// Permissions
boolean canRead = file.canRead();
boolean canWrite = file.canWrite();
boolean canExecute = file.canExecute();

// Créer/Supprimer
boolean created = file.createNewFile();  // Crée fichier
boolean deleted = file.delete();         // Supprime

// Répertoires
File dir = new File("/home/user/docs");
boolean dirCreated = dir.mkdir();        // Crée 1 niveau
boolean dirsCreated = dir.mkdirs();      // Crée plusieurs niveaux

// Lister contenu
File[] files = dir.listFiles();
String[] names = dir.list();
```

### Path Interface (Modern, Java 7+)

```java
import java.nio.file.*;

// Créer Path
Path path1 = Paths.get("data.txt");
Path path2 = Paths.get("/home/user/data.txt");
Path path3 = Paths.get("C:\\Users\\data.txt");

// Méthode alternative (Java 11+)
Path path4 = Path.of("data.txt");

// Avec plusieurs éléments
Path path5 = Paths.get("/home", "user", "data.txt");
// /home/user/data.txt

// File vers Path
File file = new File("data.txt");
Path path = file.toPath();

// Path vers File
File file2 = path.toFile();

// Propriétés Path
System.out.println(path.getFileName());      // data.txt
System.out.println(path.getParent());        // /home/user
System.out.println(path.getRoot());          // /
System.out.println(path.isAbsolute());       // true/false
System.out.println(path.toAbsolutePath());   // Chemin absolu

// Nombre d'éléments
int count = path.getNameCount();

// Accéder aux éléments
Path element = path.getName(0);  // Premier élément

// Sous-chemin
Path subpath = path.subpath(0, 2);  // Éléments 0 et 1
```

### Path Operations

```java
// Normaliser (résoudre . et ..)
Path path = Paths.get("/home/user/../data/./file.txt");
Path normalized = path.normalize();
// /home/data/file.txt

// Résoudre (combine paths)
Path dir = Paths.get("/home/user");
Path file = Paths.get("data.txt");
Path resolved = dir.resolve(file);
// /home/user/data.txt

// Relativize (chemin relatif)
Path path1 = Paths.get("/home/user/docs");
Path path2 = Paths.get("/home/user/images");
Path relative = path1.relativize(path2);
// ../images

// Real path (résout liens symboliques)
Path realPath = path.toRealPath();

// Comparer paths
boolean same = Files.isSameFile(path1, path2);
```

## 2. Operating on File and Path

### Files Class (Utility)

```java
import java.nio.file.*;

Path path = Paths.get("data.txt");

// Vérifier existence
boolean exists = Files.exists(path);
boolean notExists = Files.notExists(path);

// Type
boolean isRegularFile = Files.isRegularFile(path);

boolean isSymbolicLink = Files.isSymbolicLink(path);

// Permissions
boolean isReadable = Files.isReadable(path);
boolean isWritable = Files.isWritable(path);

// Taille
long size = Files.size(path);  // En bytes

// Attributs
FileTime modified = Files.getLastModifiedTime(path);
Files.setLastModifiedTime(path, FileTime.fromMillis(System.currentTimeMillis()));

// Hidden file?
boolean isHidden = Files.isHidden(path);
```

### Creating Files and Directories

```java
// Créer fichier
Path file = Paths.get("newfile.txt");
Files.createFile(file);  // IOException si existe déjà

// Créer répertoire
Path dir = Paths.get("newdir");
Files.createDirectory(dir);  // Un seul niveau

// Créer répertoires (plusieurs niveaux)
Path dirs = Paths.get("/home/user/a/b/c");
Files.createDirectories(dirs);  // Crée a, b, et c

// Créer fichier temporaire

// /tmp/prefix123456789.txt

// Créer répertoire temporaire

// /tmp/prefix123456789
```

### Copying and Moving

```java
Path source = Paths.get("source.txt");
Path target = Paths.get("target.txt");

// Copier fichier
Files.copy(source, target);  // IOException si target existe

// Copier avec options
Files.copy(source, target, 
    StandardCopyOption.REPLACE_EXISTING,     // Remplace si existe
    StandardCopyOption.COPY_ATTRIBUTES);     // Copie attributs

// Déplacer fichier
Files.move(source, target);

// Déplacer avec options
Files.move(source, target,
    StandardCopyOption.REPLACE_EXISTING,
    StandardCopyOption.ATOMIC_MOVE);         // Opération atomique

// Copier depuis InputStream
InputStream is = new FileInputStream("input.txt");
Files.copy(is, target, StandardCopyOption.REPLACE_EXISTING);

// Copier vers OutputStream
OutputStream os = new FileOutputStream("output.txt");
Files.copy(source, os);
```

### Deleting Files

```java
Path path = Paths.get("file.txt");

// Supprimer (exception si n'existe pas)
Files.delete(path);  // NoSuchFileException si absent

// Supprimer si existe
boolean deleted = Files.deleteIfExists(path);  // false si absent

// ATTENTION: delete() sur répertoire non-vide lance DirectoryNotEmptyException
// Supprimer récursivement
Path dir = Paths.get("mydir");
Files.walk(dir)
    .sorted(Comparator.reverseOrder())  // Fichiers avant répertoires
    .forEach(p -> {
        try {
            Files.delete(p);
        } catch (IOException e) {
            e.printStackTrace();
        }
    });
```

## 3. Introducing I/O Streams

### Stream Basics

```java
// Stream = flux de données (bytes ou caractères)
// 
// Byte Streams (données binaires):
// - InputStream / OutputStream
// - FileInputStream / FileOutputStream
// - BufferedInputStream / BufferedOutputStream
// 
// Character Streams (texte):
// - Reader / Writer
// - FileReader / FileWriter
// - BufferedReader / BufferedWriter

// Hiérarchie InputStream
// InputStream (abstract)
//   ├── FileInputStream
//   ├── ByteArrayInputStream
//   ├── FilterInputStream (abstract)
//   │     ├── BufferedInputStream
//   │     └── DataInputStream
//   └── ObjectInputStream

// Hiérarchie Reader
// Reader (abstract)
//   ├── FileReader
//   ├── StringReader
//   ├── CharArrayReader
//   ├── BufferedReader
//   └── InputStreamReader
```

### InputStream Methods

```java
// Méthodes principales d'InputStream
abstract int read() throws IOException;                    // Lit 1 byte (-1 si fin)
int read(byte[] b) throws IOException;                     // Lit dans array
int read(byte[] b, int off, int len) throws IOException;   // Lit avec offset
void close() throws IOException;                            // Ferme stream
int available() throws IOException;                         // Bytes disponibles
long skip(long n) throws IOException;                       // Saute n bytes
boolean markSupported();                                    // Support mark/reset?
void mark(int readlimit);                                   // Marque position
void reset() throws IOException;                            // Retour à mark

// Exemple
try (InputStream is = new FileInputStream("file.txt")) {
    int data;
    while ((data = is.read()) != -1) {  // Lit byte par byte
        System.out.print((char) data);
    }
}
```

### OutputStream Methods

```java
// Méthodes principales d'OutputStream
abstract void write(int b) throws IOException;              // Écrit 1 byte
void write(byte[] b) throws IOException;                    // Écrit array
void write(byte[] b, int off, int len) throws IOException;  // Écrit avec offset
void flush() throws IOException;                            // Force écriture
void close() throws IOException;                            // Ferme stream

// Exemple
try (OutputStream os = new FileOutputStream("output.txt")) {
    String text = "Hello, World!";
    os.write(text.getBytes());
    os.flush();  // Force écriture sur disque
}
```

```java
void close() throws IOException;                            // Ferme stream

// Exemple
try (Reader reader = new FileReader("file.txt")) {
```

### Writer Methods

```java
    int data;
    while ((data = fis.read()) != -1) {
        System.out.print((char) data);
    }

try (FileInputStream fis = new FileInputStream("input.txt")) {

// Écriture avec FileOutputStream
try (FileOutputStream fos = new FileOutputStream("output.txt")) {
    String text = "Hello, World!";
    fos.write(text.getBytes());

// Append mode
try (FileOutputStream fos = new FileOutputStream("output.txt", true)) {
    fos.write("More text".getBytes());
}
```

### BufferedInputStream / BufferedOutputStream

```java
// BufferedInputStream - buffer pour performance
try (BufferedInputStream bis = new BufferedInputStream(

    }
```

### BufferedReader / BufferedWriter

```java
// BufferedReader - lecture ligne par ligne
try (BufferedReader br = new BufferedReader(new FileReader("input.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {  // Lit ligne complète
        System.out.println(line);
    }

    bw.write("Line 1");
    bw.newLine();  // Nouvelle ligne (portable)

// InputStreamReader / OutputStreamWriter (bridge)
try (BufferedReader br = new BufferedReader(
        new InputStreamReader(new FileInputStream("file.txt"), "UTF-8"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
}
```

## 5. Serializing Data

### Serialization Basics

```java
import java.io.*;

// Classe sérialisable
public class Person implements Serializable {
    private static final long serialVersionUID = 1L;  // Recommandé
    
    private String name;
    private int age;
    private transient String password;  // Ne sera PAS sérialisé
    
    public Person(String name, int age, String password) {
        this.name = name;
        this.age = age;
        this.password = password;
    }
    
    // Getters/Setters
}

// Sérialiser (écrire objet)
Person person = new Person("Alice", 25, "secret");

try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("person.ser"))) {
    oos.writeObject(person);
}

// Désérialiser (lire objet)
try (ObjectInputStream ois = new ObjectInputStream(
        new FileInputStream("person.ser"))) {
    Person loaded = (Person) ois.readObject();
    System.out.println(loaded.getName());  // "Alice"
    System.out.println(loaded.getAge());   // 25
    // password est null (transient)
}
```

### transient Keyword

```java
public class User implements Serializable {
    private String username;
    private transient String password;  // Ne sera pas sérialisé
    private transient Connection connection;  // Ressources non sérialisables
    
    // password sera null après désérialisation
    // connection sera null après désérialisation
}
```

### serialVersionUID

```java
public class Person implements Serializable {
    // Version de la classe pour compatibilité
    private static final long serialVersionUID = 1L;
    
    // Si serialVersionUID change, InvalidClassException lors désérialisation
    
    // Si pas défini, Java génère automatiquement
    // Mais peut changer avec modifications de la classe
}
```

### Custom Serialization

```java
public class Person implements Serializable {
    private String name;
    private transient String password;
    
    // Custom serialization
    private void writeObject(ObjectOutputStream oos) throws IOException {
        oos.defaultWriteObject();  // Sérialiser champs normaux
        oos.writeObject(encrypt(password));  // Sérialiser password crypté
    }
    
    // Custom deserialization
    private void readObject(ObjectInputStream ois) 
            throws IOException, ClassNotFoundException {
        ois.defaultReadObject();  // Désérialiser champs normaux
        password = decrypt((String) ois.readObject());  // Décrypter password
    }
    
    private String encrypt(String text) {
        // Encryption logic
        return text;
    }
    
    private String decrypt(String text) {
        // Decryption logic
        return text;
    }
}
```


### FileVisitor

```java
import java.nio.file.attribute.*;

// FileVisitor - contrôle fin sur parcours
class MyFileVisitor extends SimpleFileVisitor<Path> {
    @Override
    public FileVisitResult visitFile(Path file, BasicFileAttributes attrs) {
        System.out.println("File: " + file);
        return FileVisitResult.CONTINUE;
    }
    
    @Override
    public FileVisitResult preVisitDirectory(Path dir, BasicFileAttributes attrs) {
        System.out.println("Entering: " + dir);
        return FileVisitResult.CONTINUE;
    }
    
    @Override
    public FileVisitResult postVisitDirectory(Path dir, IOException exc) {
        System.out.println("Leaving: " + dir);
        return FileVisitResult.CONTINUE;
    }
    
    @Override
    public FileVisitResult visitFileFailed(Path file, IOException exc) {
        System.err.println("Failed: " + file);
        return FileVisitResult.CONTINUE;
    }
}

// Utilisation
Path start = Paths.get("/home/user");
Files.walkFileTree(start, new MyFileVisitor());

// FileVisitResult options:
// - CONTINUE: continuer
// - SKIP_SUBTREE: sauter sous-répertoire
// - SKIP_SIBLINGS: sauter frères/sœurs
// - TERMINATE: arrêter complètement
```

### WatchService (Surveiller modifications)

```java
import java.nio.file.*;

// Créer WatchService
WatchService watcher = FileSystems.getDefault().newWatchService();

// Enregistrer répertoire
Path dir = Paths.get("/home/user/watched");
dir.register(watcher, 
    StandardWatchEventKinds.ENTRY_CREATE,
    StandardWatchEventKinds.ENTRY_DELETE,
    StandardWatchEventKinds.ENTRY_MODIFY);

// Boucle d'attente
while (true) {
    WatchKey key = watcher.take();  // Bloque jusqu'à événement
    
    for (WatchEvent<?> event : key.pollEvents()) {
        WatchEvent.Kind<?> kind = event.kind();
        Path filename = (Path) event.context();
        
        if (kind == StandardWatchEventKinds.ENTRY_CREATE) {
            System.out.println("Created: " + filename);
        } else if (kind == StandardWatchEventKinds.ENTRY_DELETE) {
            System.out.println("Deleted: " + filename);
        } else if (kind == StandardWatchEventKinds.ENTRY_MODIFY) {
            System.out.println("Modified: " + filename);
        }
    }
    
    boolean valid = key.reset();
    if (!valid) {
        break;  // Répertoire plus accessible
    }
}
```

## Points Clés

### File vs Path
- **File**: Legacy (Java 1.0), moins fonctionnel
- **Path**: Modern (Java 7+), plus d'opérations, meilleure gestion erreurs

### Streams
- **Byte Streams**: InputStream/OutputStream (données binaires)
- **Character Streams**: Reader/Writer (texte, encoding)
- **Buffered Streams**: BufferedReader/Writer (performance)
- **Always close**: try-with-resources

### Files Class
- **Files.readAllLines()**: Lit tout en mémoire
- **Files.lines()**: Stream lazy (grande fichiers)
- **Files.walk()**: Parcours récursif
- **Files.copy/move/delete**: Opérations fichiers

### Serialization
- **Serializable**: Interface marker
- **transient**: Champs non sérialisés
- **serialVersionUID**: Contrôle version
- **ObjectInputStream/ObjectOutputStream**: Sérialisation

### Console vs Scanner
- **Console**: Masquage mot de passe, null en IDE
- **Scanner**: Plus flexible, parsing types

## Questions sur File et Path

**Q1: Quelle est la différence entre File et Path?**

**R:**

| **File** | **Path** |
|----------|----------|
| Java 1.0 (legacy) | Java 7+ (NIO.2) |
| Classe concrète | Interface |
| Moins de fonctionnalités | Plus de fonctionnalités |
| Gestion erreurs limitée | Meilleure gestion erreurs |
| Moins performant | Plus performant |

```java
// File (ancien)
File file = new File("data.txt");
boolean exists = file.exists();
file.delete();

// Path (moderne)
Path path = Paths.get("data.txt");
boolean exists = Files.exists(path);
Files.delete(path);  // Meilleure gestion erreurs

// Conversion
File file = new File("data.txt");
Path path = file.toPath();  // File → Path
File file2 = path.toFile();  // Path → File
```

**Q2: Ce code crée-t-il un fichier?**
```java
File file = new File("data.txt");
```

**R:** **NON**. Crée seulement un **objet File** en mémoire, pas le fichier physique.

```java
File file = new File("data.txt");
System.out.println(file.exists());  // false (fichier n'existe pas)

// Pour créer le fichier physique
file.createNewFile();  // Maintenant le fichier existe
```

**Q3: Quelle est la différence entre ces deux?**
```java
// Version 1
File file = new File("data.txt");

// Version 2
File file = new File("/home/user/data.txt");
```

**R:**
- **Version 1**: Chemin **relatif** (par rapport au répertoire actuel)
- **Version 2**: Chemin **absolu** (depuis la racine)

```java
// Chemin absolu
File absolute = new File("/home/user/data.txt");
System.out.println(absolute.getPath());          // "/home/user/data.txt"
System.out.println(absolute.isAbsolute());       // true
```

**Q14: Peut-on supprimer un répertoire non-vide avec delete()?**

```java
Files.walk(dir)
    .sorted(Comparator.reverseOrder())  // Enfants avant parents
    .forEach(path -> {
        try {
            Files.delete(path);
        } catch (IOException e) {

            throws IOException {
        Files.delete(file);
        return FileVisitResult.CONTINUE;
    }
    
    @Override
    public FileVisitResult postVisitDirectory(Path dir, IOException exc) 
            throws IOException {
        Files.delete(dir);
        return FileVisitResult.CONTINUE;
    }
});
```

**Q19: Pourquoi utiliser BufferedInputStream/BufferedOutputStream?**

**R:** Pour **améliorer les performances** en réduisant les accès disque.

```java
// Sans buffer - LENT (accès disque pour chaque byte)

    int data;
    while ((data = fis.read()) != -1) {  // 1 accès disque par byte!
        // Traiter
    }
}

try (BufferedInputStream bis = new BufferedInputStream(
        new FileInputStream("large.txt"))) {
    int data;
    while ((data = bis.read()) != -1) {  // Buffer de 8192 bytes par défaut
        // Traiter
    }
}

// Gain de performance typique: 10-100x plus rapide
```

## Questions sur Serialization

**Q31: Qu'est-ce que Serializable?**

**R:** **Interface marker** permettant de **sauvegarder** un objet.

```java
// Sans Serializable
public class Person {
    private String name;
    private int age;
}

ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("person.ser"));
oos.writeObject(new Person("Alice", 25));  // NotSerializableException

// Avec Serializable
public class Person implements Serializable {
    private String name;
    private int age;
}

ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("person.ser"));
oos.writeObject(new Person("Alice", 25));  // OK
```

---

**Q32: Que fait le mot-clé transient?**

**R:** Indique qu'un champ ne doit **PAS être sérialisé**.

```java
public class User implements Serializable {
    private String username;
    private transient String password;  // Ne sera PAS sérialisé
    private int age;
}

// Sérialisation
User user = new User("alice", "secret123", 25);
ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("user.ser"));
oos.writeObject(user);

// Désérialisation
ObjectInputStream ois = new ObjectInputStream(new FileInputStream("user.ser"));
User loaded = (User) ois.readObject();

System.out.println(loaded.username);  // "alice"
System.out.println(loaded.password);  // null (transient)
System.out.println(loaded.age);       // 25
```

---

**Q33: Quels champs sont automatiquement transient?**

**R:** Les champs **static** et **transient**.

```java
public class Example implements Serializable {
    private int instance = 1;           // Sérialisé
    private static int staticField = 2;  // PAS sérialisé (static)
    private transient int trans = 3;     // PAS sérialisé (transient)
}

// Après sérialisation/désérialisation
System.out.println(loaded.instance);      // 1
System.out.println(loaded.staticField);   // Valeur actuelle de la classe
System.out.println(loaded.trans);         // 0 (valeur par défaut)
```

**Q34: À quoi sert serialVersionUID?**

**R:** Contrôle la **version** de la classe pour compatibilité.

```java

// Si serialVersionUID change
private static final long serialVersionUID = 2L;

// Mais peut changer si classe modifiée (ajout méthode, etc.)

```

**Q44: Que fait FileVisitor?**

**R:** **FileVisitor** permet un contrôle fin sur le parcours de répertoires.

```java
class MyVisitor extends SimpleFileVisitor<Path> {
    private int fileCount = 0;
    private int dirCount = 0;
    
    @Override
    public FileVisitResult visitFile(Path file, BasicFileAttributes attrs) {
        fileCount++;
        System.out.println("File: " + file);
        return FileVisitResult.CONTINUE;
    }
    
    @Override
    public FileVisitResult preVisitDirectory(Path dir, BasicFileAttributes attrs) {
        dirCount++;
        System.out.println("Entering: " + dir);
        return FileVisitResult.CONTINUE;
    }
    
    @Override
    public FileVisitResult postVisitDirectory(Path dir, IOException exc) {
        System.out.println("Leaving: " + dir);
        return FileVisitResult.CONTINUE;
    }
    
    @Override
    public FileVisitResult visitFileFailed(Path file, IOException exc) {
        System.err.println("Failed to access: " + file);
        return FileVisitResult.CONTINUE;
    }
    
    public void printStats() {
        System.out.println("Files: " + fileCount);
        System.out.println("Directories: " + dirCount);
    }
}

// Utilisation
MyVisitor visitor = new MyVisitor();
Files.walkFileTree(Paths.get("/home/user"), visitor);
visitor.printStats();
```

**Q46: Comment surveiller un répertoire avec WatchService?**

**R:**

```java
import java.nio.file.*;

// Créer WatchService
WatchService watcher = FileSystems.getDefault().newWatchService();

// Enregistrer répertoire
Path dir = Paths.get("/home/user/watched");
WatchKey key = dir.register(watcher,
    StandardWatchEventKinds.ENTRY_CREATE,
    StandardWatchEventKinds.ENTRY_DELETE,
    StandardWatchEventKinds.ENTRY_MODIFY);

System.out.println("Watching: " + dir);

// Boucle d'écoute
while (true) {
    WatchKey watchKey;
    try {
        watchKey = watcher.take();  // Bloque jusqu'à événement
    } catch (InterruptedException e) {
        break;
    }
    
    // Traiter événements
    for (WatchEvent<?> event : watchKey.pollEvents()) {
        WatchEvent.Kind<?> kind = event.kind();
        Path filename = (Path) event.context();
        
        if (kind == StandardWatchEventKinds.ENTRY_CREATE) {
            System.out.println("Created: " + filename);
        } else if (kind == StandardWatchEventKinds.ENTRY_DELETE) {
            System.out.println("Deleted: " + filename);
        } else if (kind == StandardWatchEventKinds.ENTRY_MODIFY) {
            System.out.println("Modified: " + filename);
        } else if (kind == StandardWatchEventKinds.OVERFLOW) {
            System.out.println("Events lost");
        }
    }
    
    // Reset key
    boolean valid = watchKey.reset();
    if (!valid) {
        System.out.println("Key no longer valid");
        break;
    }
}
```

**Q44: Que fait FileVisitor?**

**R:** **FileVisitor** permet un contrôle fin sur le parcours de répertoires.

```java
class MyVisitor extends SimpleFileVisitor<Path> {
    private int fileCount = 0;
    private int dirCount = 0;
    
    @Override
    public FileVisitResult visitFile(Path file, BasicFileAttributes attrs) {
        fileCount++;
        System.out.println("File: " + file);
        return FileVisitResult.CONTINUE;
    }
    
    @Override
    public FileVisitResult preVisitDirectory(Path dir, BasicFileAttributes attrs) {
        dirCount++;
        System.out.println("Entering: " + dir);
        return FileVisitResult.CONTINUE;
    }
    
    @Override
    public FileVisitResult postVisitDirectory(Path dir, IOException exc) {
        System.out.println("Leaving: " + dir);
        return FileVisitResult.CONTINUE;
    }
    
    @Override
    public FileVisitResult visitFileFailed(Path file, IOException exc) {
        System.err.println("Failed to access: " + file);
        return FileVisitResult.CONTINUE;
    }
    
    public void printStats() {
        System.out.println("Files: " + fileCount);
        System.out.println("Directories: " + dirCount);
    }
}

// Utilisation
MyVisitor visitor = new MyVisitor();
Files.walkFileTree(Paths.get("/home/user"), visitor);
visitor.printStats();
```

**Q45: Quelles sont les valeurs de FileVisitResult?**

**Q46: Comment surveiller un répertoire avec WatchService?**

**R:**

```java
import java.nio.file.*;

// Créer WatchService
WatchService watcher = FileSystems.getDefault().newWatchService();

// Enregistrer répertoire
Path dir = Paths.get("/home/user/watched");
WatchKey key = dir.register(watcher,
    StandardWatchEventKinds.ENTRY_CREATE,
    StandardWatchEventKinds.ENTRY_DELETE,
    StandardWatchEventKinds.ENTRY_MODIFY);

System.out.println("Watching: " + dir);

// Boucle d'écoute
while (true) {
    WatchKey watchKey;
    try {
        watchKey = watcher.take();  // Bloque jusqu'à événement
    } catch (InterruptedException e) {
        break;
    }
    
    // Traiter événements
    for (WatchEvent<?> event : watchKey.pollEvents()) {
        WatchEvent.Kind<?> kind = event.kind();
        Path filename = (Path) event.context();
        
        if (kind == StandardWatchEventKinds.ENTRY_CREATE) {
            System.out.println("Created: " + filename);
        } else if (kind == StandardWatchEventKinds.ENTRY_DELETE) {
            System.out.println("Deleted: " + filename);
        } else if (kind == StandardWatchEventKinds.ENTRY_MODIFY) {
            System.out.println("Modified: " + filename);
        } else if (kind == StandardWatchEventKinds.OVERFLOW) {
            System.out.println("Events lost");
        }
    }
    
    // Reset key
    boolean valid = watchKey.reset();
    if (!valid) {
        System.out.println("Key no longer valid");
        break;
    }
}
```

**Q60: Comment copier un répertoire récursivement?**

```java
    @Override
    public FileVisitResult visitFile(Path file, BasicFileAttributes attrs) 
            throws IOException {
        Path targetFile = target.resolve(source.relativize(file));
```
